# Comparing peer language versions and authority

Use when language versions are known coequal, their authority is disputed, or a comparison must not presume one canonical original. Ordinary directional translation remains unchanged.

1. Establish exact version identities, dates, relevant clauses, declared lineage (derived, peer, mixed, unknown) and authority separately. Equal authenticity can be a legal/institutional or project-specific fact; do not infer it because versions coexist or because direction is unknown. Check controlling source where consequential; unknown stays unknown.
2. Choose an analytical anchor or compare pairs symmetrically; label the direction as analytical, not a claim of source supremacy. Compare propositions, scope, modality, exceptions, referents, terms and any differences affecting the brief. Distinguish actual textual discrepancy, possible interpretation and unsupported cause. Track versions and scope, not just language names.
3. Preserve materially divergent readings and unresolved authority; neither fluency, translation confidence, most recent timestamp nor number of agreeing versions decides authoritative meaning. A translation skill does not settle law, project behavior, certification or other normative commitments. Route interpretation requiring authority to the responsible human/institution or the existing specification/decision owner as applicable.
4. Return a comparison with exact version anchors and consequences, supported alternatives/conditional questions and remaining uncertainties. No unsolicited synchronization, canonical change or replacement. If user requests an authorized update, Translation handles target changes within actual authority. Use existing structured exchange fields for directional anchors when requested; if the authority relation cannot fit the current schema, report it in allowed notes or a separately requested representation. Do not invent new required fields or encode legal supremacy in source_id.

Synthetic example: two stipulated coequal clauses say “at least one” and “exactly one.” Report divergence in allowed cardinality and potential consequence; request the competent interpretation if material. Do not choose the more fluent version. This is not evidence of an actual statute.

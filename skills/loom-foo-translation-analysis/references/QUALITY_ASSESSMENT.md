# Purpose-specific translation quality assessment

Use when the requested result is translation QA, prioritization of defects, comparative evaluation of candidates, or actionable revision recommendations. Keep the ordinary transformation method for simple comparisons; not all changes are errors and a review does not authorize modifying text.

1. Bind the actual source/target revisions, task/brief, locale, domain, evaluator role, protected content and requested evaluation unit (span, document, artifact). If an applicable project rubric is supplied, use its exact version and definitions. Separate objective fidelity, suitability, fluency, style, voice/aesthetic trade-offs, and structural validity. Do not invent weights, numeric scores, confidence percentages or universal quality thresholds. No metric or model output alone proves equivalence.
2. Align material properties using the existing transformation method; check context and alternative readings. Record actual finding anchors, transformation, assessment, evidence, severity/impact under the brief and confidence separately. Distinguish source defect, translation defect, legitimate locale/genre variation, optional preference and unresolved question. For high-stakes content describe possible consequences and the required qualified confirmation rather than certifying.
3. Prioritize by consequence for this use (e.g. safety, obligation, wrong action, attribution, readability), not the number of flags. Apply a specified severity scale only when it fits; report actual evidence and uncertainty. Group repeated findings by mechanism when useful, retain affected locations and exceptions, distinguish one repeated issue from independent defects. Follow a supplied repetition/penalty rule only if authoritative. No arbitrary double scoring.
4. Select the evaluation method to answer the real question: property-level anchored error diagnosis for correction; holistic read for discourse/voice; pairwise comparison for competing literary or pragmatic alternatives with explicit criteria. Keep evaluator disagreement and trade-offs rather than claiming a universal ranking. If testing a draft-independent alternative, actually isolate its context and freeze output, or label prior exposure; do not call a same-context alternative blind.
5. Return material findings with supported repair options and priority; report no material error if supported. A proposal does not change the artifact. If user also requests the revised target, Translation owns authorized scoped repair. Recheck actual revised content only if provided/observed; distinguish recommendations, implemented revisions and acceptance. Do not claim reader behavior or measured utility without evidence.

Synthetic contrast: `The payment may be refunded` vs `Платіж буде повернено` shifts possibility to guarantee (material under a fidelity brief). A contextually interchangeable synonym need not be penalized. A literary choice may preserve plot but change rhythm: evaluate according to its brief, not number of lexical differences.

# typography — conditional method

> Preserved sections from private Loom-foo 0.35.1 SKILL.md. Referenced `references/...` paths are relative to the owning skill root. L1 activation and authority remain controlling.

## Quick cases

- “Build an English/Ukrainian type scale for this responsive dashboard” -> typography; type roles/tokens, mixed-script specimens and actual viewport checks.
- “Improve this long-form report's line breaks, fonts and paragraph rhythm, preserve the wording” -> typography; actual edited artifact and render QA.
- “Перевір лише гліфи Ґ/Ї та відсутність обрізання тексту на 200% zoom, без редагування” -> Typography, scoped technical diagnosis.
- “Оціни готовий постер: що слабке в композиції та типографіці?” -> Design Review, cross-disciplinary critique.
- “Proofread Ukrainian spelling in this paragraph” -> editorial review, **not** typography.
- “Make a visual poster for an event” -> integrated design/graphic design, with typography methods if the type work is central; don't require Typography for every graphic.
- “Design a complete Figma component library with tokens and variants” -> Figma/design-systems tool owner; Typography contributes type subsystem only when requested.

# Identity artifact completeness and honest verification

- **Editable source:** native/vector/logo paths where requested. Raster image export isn't SVG or editable vector; auto-trace is not guaranteed faithful.
- **Variants:** correct mark family, grayscale/one-color and reversed as appropriate; no accidental gaps/overlaps, distorted lockups or substituted fonts.
- **Small/large application:** inspect tiny icon/favicons, interface headers and print/display size as required. Check optical center, counterforms, negative space, stroke consistency and clipping.
- **Language:** verify full brand name in every required script (including Ukrainian Ґ/ґ, Ї/ї, Є/є, І/і) and correct line-breaking/diacritics. Wordmark letterforms and names are not automatically interchangeable across scripts.
- **Rights:** mark similarity search is research, not trademark clearance. Check available font/asset license before commercial production; never transfer font binaries to the user unless clearly licensed/authorized.
- **Export:** verify dimensions, color space/profile, transparent backgrounds, naming and source links for actual file set. Mockups are illustrative applications and must not replace identity files.
- **Delivery status:** `CONCEPT`, `SOURCE_READY`, `PRODUCTION_CANDIDATE`, `PRODUCTION_VERIFIED` only with corresponding direct evidence.

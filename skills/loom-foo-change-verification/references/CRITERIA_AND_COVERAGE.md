# Criteria and Coverage

## Criteria authority
Resolve criteria from accepted controlling sources. Do not invent or relax them.

Potential sources:
- Specification;
- accepted architecture constraint;
- Task Brief acceptance criteria;
- review finding resolution criterion;
- remediation contract;
- release/promotion gate;
- explicitly applicable external standard.

## Coverage mapping
For each property ask:
1. What exactly must hold?
2. What check/evidence can establish/falsify it?
3. What environment/fidelity matters?
4. What was actually observed?
5. What remains unproven?

## Check quality
A check is useful only when it can change the property result.

Passing a generic test suite does not prove a property absent coverage mapping.

## Regression scope
Include changed properties and plausible collateral effects. Broaden only when claim/coupling/history requires it.

## Escalation
If credible check design itself is a research problem, route to research-design or a specialist method owner.

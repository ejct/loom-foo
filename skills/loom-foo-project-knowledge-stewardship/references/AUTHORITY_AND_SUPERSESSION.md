# Authority and Supersession

## Authority

Never infer durable authority from output quality, recency, location, PASS/CONVERGED state, merge state, or assistant authorship.

Resolve separately:
1. semantic/artifact authority;
2. acceptance/canon authority;
3. permission to mutate persistent project sources;
4. runtime capability to perform the mutation.

If (2) or (3) is absent, do not apply durable reconciliation.

## Supersession

Prefer project-native prospective supersession:
- preserve the previous artifact;
- mark/link its replacement where the project convention permits;
- point current navigation/source maps to the new current source;
- keep prior run/evidence identities intact.

Do not rewrite historical evidence or old decision rationale to reflect the new state.

## Conflict

Different text is not automatically an authority conflict.

First ask whether one source is authoritative and the other is merely a stale derived view. Only return `AUTHORITY_CONFLICT` when controlling authority itself is contradictory or precedence cannot be resolved.

# Design Review — medium-dependent lenses and limits

Select only lenses relevant to task and actual evidence.

## Typography and editorial
- Reading hierarchy, scripts and actual glyphs, copy legibility, line breaks, alignment, type weight/size, measure and pacing.
- For multi-page work inspect representative/critical pages and source copy completeness; if not all pages were inspected do not assert whole-book correctness.
- Language errors belong to editorial review; don't silently change wording when assessing typography.

## UI / interaction
- Primary task, object/action model, signifiers, state semantics, feedback, errors/recovery, focus/keyboard order when runnable, responsive, content density, long strings, loading/empty states.
- A screenshot can establish visible hierarchy/spacing but **not** functioning interactions, screen reader output, real usability or unrendered states.

## Graphic, brand, icons
- Graphic: composition, meaningful hierarchy, image/text relation, proportions, reproduction, distinctive visual idea and real channel constraints.
- Brand: formal consistency, usage context, reversals, type/identity harmony, real small-size marks; uniqueness/trademark rights are not established visually.
- Icons: actual target pixel sizes, optical balance, counters/negative space, weight/stroke coherence, pixel grid and variant exports; don't judge only a large render.

## Information graphics
- What is being claimed, visually encoded magnitudes/relations, reading order, legends/units, source/number provenance, potential deceptive scaling, uncertainty and text clarity.
- Verification of numerical computation belongs to the Data owner. A chart screenshot cannot establish the true source values without evidence.

## Motion, 3D and physical
- Motion: time hierarchy, meaningful transitions, duration and frame coherence; playback and sequence are needed to verify behavior.
- 3D: scale, views, geometry, materials, lighting, topology when source accessible; beauty render is not mesh acceptance.
- Print/packaging: substrate, trim, bleed, embedded fonts, real output profile and proofs; don't claim prepress without the actual file and printer specs.

## Cross-cutting

Preserve authorial intent and source truth. State unresolved evidence for accessibility, print readiness, IP/licensing and hidden technical properties rather than converting a generic checklist into a pass.

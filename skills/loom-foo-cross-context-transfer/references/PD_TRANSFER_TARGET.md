## 13. Independent target baseline

For target-specific work, resolve current canonical target identity and material rename/supersession history, then inspect target state before adapting source units:

- current owners/mechanisms;
- accepted decisions/constraints;
- current failures/gaps;
- relevant evidence;
- architecture/product/process boundaries.

This pass must not be driven only by source terminology. For indexed projects, follow the verified knowledge-source entrypoint → entity inventory or equivalent → project knowledge record when available → controlling project-native authority as needed. Reuse relevant, source-grounded project context already acquired by Link Intake or another specialist instead of duplicating connector reads. Preserve index-as-discovery versus project-native-as-authority distinctions. If sources cannot be reached, mark target-specific findings provisional or unresolved; do not silently substitute old names or remembered state.

After Transfer Units exist, expand target reading by affected concerns.
## 14. Structural mapping

For each unit ask:

1. What target concern corresponds?
2. Are the same forces present?
3. Do source boundary conditions hold?
4. Which assumptions survive?
5. Does the mechanism preserve the same causal role?
6. What adaptation is needed?
7. What would fail if the analogy is wrong?

Surface similarity is a probe, not evidence.
## 15. Target Reception Gate

For each candidate transfer:

1. What target problem would it solve?
2. Does target already solve it?
3. Is there an existing owner that should absorb the lesson?
4. Are source forces present?
5. Does it conflict with accepted target decisions?
6. What is the smallest credible local delta?
7. Is any delta actually required?

Dispositions:

`ALREADY_PRESENT`
`DIRECT_FIT`
`ADAPT`
`MERGE_WITH_EXISTING`
`SYNTHESIS_CANDIDATE`
`VALIDATION_REQUIRED`
`DEFER`
`NO_FIT`
`CONFLICT`

A useful source lesson does not imply a target change.
## 16. Multi-source synthesis

Preserve per-source provenance/evidence. Identify convergence, contradiction, complementarity, and contextual variants.

Do not let the most detailed source dominate by verbosity. Distinguish independent support from repeated copying of one upstream idea.

A synthesis may reveal a broader shared substrate; mark it candidate, not accepted abstraction.

# Challenge and Evidence

## Principle

Challenge improves an Understanding Model only when it can reveal a material alternative, contradiction, assumption, or discriminator.

It is not a ritual.

## Same-model limitation

A second pass by the same model/context is an adversarial reasoning aid, not independent validation.

Do not convert repeated agreement with yourself into stronger evidence.

## Preferred hierarchy

When practical, prefer:

1. authoritative/current project source;
2. direct observation or deterministic check;
3. bounded external verification;
4. discriminating empirical probe;
5. structured comparison of competing explanations;
6. introspective critique.

This is not a universal evidence ranking; use domain-specific authority when it is stronger.

## Alternative-generation rule

Before declaring the current explanation strongest, ask whether the considered set is plausibly incomplete.

Generate alternatives only when they could explain material observations differently.

Avoid "three options" padding.

## Assumption rule

Surface an assumption when:

- the conclusion depends on it; and
- it is not already established.

Do not inventory trivial assumptions.

## Crux rule

A crux is an unresolved statement/observation whose resolution could materially change the current Understanding Model or routing.

If the crux is empirical and consequential, route to research-design rather than elaborating speculative reasoning.

## Stop rule

Stop challenge when:

- no material alternative or contradiction remains;
- remaining uncertainty is explicit;
- direct evidence is now required;
- another pass is unlikely to change the model.

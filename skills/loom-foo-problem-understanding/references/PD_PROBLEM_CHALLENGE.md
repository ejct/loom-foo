## 5. Generate alternatives when material

Do not evaluate only the frame already present if a missing alternative could change the conclusion.

Generate a small number of plausible competing:

- frames;
- explanations;
- causal models;
- problem definitions;
- scope boundaries.

Do not manufacture alternatives for symmetry. If one model is already strongly established and no material competitor is plausible, keep it.
## 6. Challenge conditionally

Challenge is a tool, not a mandatory loop.

Use proportionate checks such as:

- load-bearing assumptions;
- contradictions;
- counterexamples;
- outside view / reference class;
- competing hypotheses;
- causal attribution check;
- premortem;
- sensitivity / crux search.

Do not repeat critique passes merely to make the analysis look rigorous.

Same-context self-critique is not independent validation.

Read `references/CHALLENGE_AND_EVIDENCE.md` for the evidence boundary.
## 7. Prefer discriminating evidence when cheap

When current sources, direct inspection, retrieval, deterministic checks, or a bounded empirical probe can resolve the controlling uncertainty more reliably than introspection, prefer that route.

If substantial new evidence must be designed, hand off to `loom-foo-research-design`.

If evidence already exists and the primary question is what it supports, hand off to `loom-foo-evidence-review`.

Do not silently perform a large research program under this skill.

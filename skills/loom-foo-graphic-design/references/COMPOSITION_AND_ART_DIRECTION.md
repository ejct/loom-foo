# Composition and art direction — applied decisions

Read for consequential layout or visual concept work. This is a choice guide, not a prescribed style.

## Message-first compositional reasoning

- State one sentence that the audience should take away, then rank indispensable vs supporting copy and what may be omitted only with permission.
- Name a primary focal relationship (dominance, contrast, framing, alignment, directional flow, visual metaphor, sequence). Avoid accidental competition between headline, hero image and decorative accents.
- Test the work at first glance, normal viewing size and reduced thumbnail. A compelling full-screen mock can collapse at 250 px or a mobile crop.
- Treat white space as content spacing and sequencing, not automatic minimalism. Dense compositions can be correct if hierarchy and rhythm are legible.
- Grid, asymmetry, modular systems, overlap and tension are alternatives. Pick based on copy, cultural context and medium; explain departures from conventional alignment when they materially improve meaning.

## Language and image interplay

- Use real bilingual copy; check length and script expansion. Do not derive translated wording from a visual model's pixels.
- A typeface carries meaning but must support intended glyphs/weights and licensing. Deep type decisions belong to Typography; the graphic owner must still inspect its rendered output.
- Illustrations/photographs must support, not falsify, the subject. Distinguish licensed/source image from generated material and compositional stand-in.
- Avoid 'AI slop' via actual decisions: no generic gradient/glow/chrome, decorative charts, filler text or pseudo-content unless appropriate to the brief.

## Coherent families / campaigns

Define invariant elements (voice, geometry, type roles, color functions, image treatment, recognizable proportions) and variable elements (headline length, subject crop, language, channel ratio). A campaign is not identical scaling of one key visual: each format should preserve semantic priority under its constraints.

When reviewing a choice, ask: What specific competing composition would better meet the same purpose? What trade-off makes the current one preferable? Avoid ungrounded universal claims that one alignment or color improves conversions.

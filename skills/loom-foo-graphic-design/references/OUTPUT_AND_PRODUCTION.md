# Graphic output and production boundaries

## Artifact selection

| Need | Deliver/check | Never substitute |
| --- | --- | --- |
| Poster or social graphic | Requested exact dimensions, controlled text, crop and source/export as specified | One generic square mockup for all formats |
| Editorial spread or report | Complete copy, pages/spreads, readable styles, page flow and editable document when requested | Cover-only artwork |
| Vector graphic | SVG/PDF/vector source if truly created and inspected | Raster export labelled vector |
| Image-led concept | Provenance/license of supplied images, expected raster format/resolution | Placeholder treated as verified licensed asset |
| Production print | Actual size, bleed/safe zones, profile, linked assets, printer-specific format and applicable PDF/X proof | Normal PDF claimed preflighted without checking |

For a physical target, get printer/fabricator requirements when truly necessary. Missing target color profile and preflight tools => `PRODUCTION_VERIFICATION_PENDING`, not an invented PASS. Relevant print standards are conditional on provider instructions, not assumed universal.

## Specific defects to seek

Clipping near crop lines, type near unsafe zones, wrong image aspect, fake/upscaled resolution, mismatch between format variants, locale-specific line breaks, source text omissions, weak contrast for intended distance, icons inconsistent with visual grammar, inaccessible color-only distinctions when relevant.

If requested delivery cannot be made in this runtime, say exactly which artifact is deliverable and what is blocked; do not quietly downgrade to a moodboard or text plan.

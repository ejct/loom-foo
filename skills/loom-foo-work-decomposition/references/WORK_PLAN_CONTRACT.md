# Work Plan Contract

A Work Plan is a semantic planning artifact between accepted design/intent and one-unit task compilation.

When material, it should make recoverable:
- controlling accepted source(s);
- target outcome/scope/non-goals;
- work units and unit outcomes;
- unit subject/scope;
- acceptance boundary;
- distinct authority boundary;
- dependencies/prerequisites;
- outputs used downstream;
- gates;
- parallelism;
- integration/reconciliation points;
- plan completion condition;
- unresolved upstream blockers.

A plan is ready when the accepted target is covered without obvious omission and each executable unit can be handed to agent-task-design without replanning the whole program.

A valid plan may contain blocked future units when the blocking gate is explicit.

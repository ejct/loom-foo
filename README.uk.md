# loom-foo · v0.57.0

**Трохи більше майстерності для ваших AI-агентів.**

**Мова:** [English](README.md) · Українська

45 спеціалізованих Agent Skills в одному пакеті — для дизайну, досліджень, роботи з текстами, перекладу, планування, інженерії та роботи зі знаннями.

Сформулюйте завдання асистентові як зазвичай. Loom-foo надає йому методики, які можна добирати, за потреби поєднувати й застосовувати до конкретної роботи.

> **Попередня версія вихідного коду.** Код доступний тут; окремого публічного дистрибутива або релізу в каталозі плагінів поки немає. Див. [статус релізу](RELEASE_STATUS.md).

## Як користуватися

Якщо Loom-foo встановлено в сумісному AI-клієнті, працюйте як зазвичай. Асистент може добирати відповідні навички залежно від підтримки їх виявлення та активації у клієнті.

У ChatGPT, якщо Loom-foo встановлено й доступно для вибору, можна явно викликати його через `@loom-foo` разом із завданням. Не потрібно запам'ятовувати назви навичок чи самостійно складати робочий процес.

## Як це працює

Loom-foo використовує [формат Agent Skills](https://agentskills.io/). Кожна навичка містить інструкції та, за потреби, довідкові матеріали чи скрипти. Асистент може добирати потрібні методики, завантажувати додаткові матеріали й поєднувати взаємодоповнювальні навички.

Акцент — на конкретних результатах, доказовості, пропорційних зусиллях, явному позначенні невизначеності та перевірці. Інструкції не надають повноважень. Фактичне виявлення, активація та виконання залежать від клієнта.

Платний API, сервер розробника або централізований оркестратор не потрібні.

## Доступність і встановлення

Репозиторій містить [портативні навички](skills/) та маніфести для ChatGPT, Claude, Codex, Antigravity і Gemini. Для ознайомлення з кодом або розробки:

```sh
git clone https://github.com/ejct/loom-foo.git
```

Клонування репозиторію не означає встановлення. Спосіб встановлення та автоматичний добір навичок залежать від клієнта. Поточний кандидат **ще не допущено до публікації** як інсталяційний дистрибутив.

Для роботи безпосередньо з вихідними матеріалами надайте сумісному агенту доступ до колекції навичок. Див. [формат Agent Skills](https://agentskills.io/) та документацію вашого клієнта.
